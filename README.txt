PUBLICARE GITHUB PAGES
1. Creează un repository public pe GitHub.
2. Încarcă index.html, style.css, script.js și întregul folder assets (cu toate fișierele).
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Pentru domeniu .ro: Settings > Pages > Custom domain, apoi configurează DNS la registrar.
Documentație: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
